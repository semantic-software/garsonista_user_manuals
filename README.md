# User Manuals — Garsonista Web App

Αναλυτικά εγχειρίδια χρήσης, σεταρίσματος και αντιμετώπισης καθημερινών ζητημάτων,
γραμμένα για **δύο κοινά**:

- τον **απλό χρήστη** του καταστήματος (ταμείο, υπεύθυνος βάρδιας, υπεύθυνος delivery)
- τον **τεχνικό** που στήνει και παραμετροποιεί το πρόγραμμα σε πελάτες

Τα αρχεία αυτά τροφοδοτούν και τον **support agent** του site — γράφουμε με πλήρεις,
αυτόνομες προτάσεις, ονομάζουμε τα κουμπιά/πεδία **ακριβώς όπως εμφανίζονται στο UI**,
και κάθε ενότητα απαντάει σε ένα συγκεκριμένο «πώς κάνω…» ή «γιατί δεν…».

## Κανόνες συγγραφής

1. **Ένα module ανά αρχείο.** Τίτλοι ενοτήτων = πραγματικές ερωτήσεις/εργασίες χρήστη.
2. **Βήματα αριθμημένα**, με τα labels του UI σε «εισαγωγικά» όπως φαίνονται στην οθόνη.
3. Κάθε αρχείο κλείνει με **«Συχνά προβλήματα & λύσεις»** (σύμπτωμα → αιτία → λύση)
   και ενότητα **«Για τεχνικούς»** (ενεργοποιήσεις, δικαιώματα, κανόνες λειτουργίας).
4. Ό,τι απαιτεί ενέργεια admin/τεχνικού σημειώνεται ρητά με **[ΤΕΧΝΙΚΟΣ]**.
5. **ΠΟΤΕ κώδικας, ονόματα πινάκων ή πεδίων βάσης δεδομένων.** Τα εγχειρίδια
   απευθύνονται σε χρήστες και τεχνικούς πεδίου (όχι developers) και τροφοδοτούν
   τον support agent — μόνο ονόματα οθονών/κουμπιών/ρυθμίσεων όπως φαίνονται στο
   UI. Ό,τι αφορά βάση/κώδικα ανήκει στον φάκελο `docs/` (developers).
